# Clear instructions beat clever ones

The single highest-leverage prompt-engineering move is also the most boring: say exactly what you want, in plain language, with the constraints that matter. Cleverness comes later — and only when clarity isn't enough.

## A concrete example

A vague prompt:

```
Summarize this article.
```

A clear prompt:

```
Summarize the article below in 3 bullets, each under 20 words. Lead with the
main finding. Use plain language a non-expert can follow. If a number is in
the article, include it.
```

The second one is longer because it pins down the four things the first one left to chance: length, structure, audience, and what to keep.

<Callout kind="tip">
When a prompt fails, your first move should be to add a constraint, not to add cleverness.
</Callout>
