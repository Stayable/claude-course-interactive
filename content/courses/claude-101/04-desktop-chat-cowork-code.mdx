# Claude desktop app: Chat, Cowork, Code

Lesson 01 introduced the surfaces in a glance. This lesson goes one level deeper into what *each* one is actually for, so you stop wondering which to open.

The Claude desktop app is one window with three modes. Same model underneath. Different working style.

<Diagram
  takeaway="One window, three modes. Pick the mode that matches the shape of the work."
  chart={`flowchart TB
    D[Claude desktop app]
    D --> Chat[Chat<br/>Talk to Claude]
    D --> Cowork[Cowork<br/>Work alongside Claude on files]
    D --> Code[Code<br/>Hand Claude a codebase]
    Chat -.->|"messages"| out1[Replies in the chat]
    Cowork -.->|"file edits"| out2[Real files on your disk]
    Code -.->|"commits, runs"| out3[A whole repo]`}

## Chat

The default. A conversation with Claude in the desktop window. Nothing on your computer is touched unless you attach it to the message.

Use Chat when:

- You're thinking out loud and want a smart sounding-board.
- You're drafting something that'll live in your head or in another app.
- The task is short — one or two turns of back-and-forth.

If a task could fit in a single chat thread, Chat is almost always the right surface.

## Cowork

Cowork is Chat plus *real files*. You point Claude at a folder or document, and it can read, edit, and create files there directly. You see the diffs before they happen.

Use Cowork when:

- The work crosses more than one file — a proposal with an attached spreadsheet, a slide deck with notes, a draft contract with redlines.
- You want Claude to actually *do* the edit, not just describe it.
- You want to review changes before they land.

<Callout kind="tip">
Cowork's superpower is that the conversation stays in one place. You don't paste the document in, get a rewrite, paste it back, lose your place. Claude works on the file with you.
</Callout>

## Code

Code is for software work. You hand Claude a codebase. It can read every file, run commands, write tests, fix bugs, and commit changes. You're still the one driving — Claude pauses for permission on anything risky.

Use Code when:

- You're shipping software.
- The task spans many files or needs to *run* something to verify.
- You want a record (commits, diffs) of what changed and why.

There's a separate **Claude Code 101** course for this surface — that's where to go next if Code is your main use.
