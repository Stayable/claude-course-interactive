# Appendix 10.1: Chaining prompts

Sometimes a task is too big for a single Claude call to do well. The fix is to **chain** prompts: take the output of one call, feed it (or a slice of it) into the next. Each step does one job. The whole pipeline does the big thing.

## Two common shapes

<Diagram
  takeaway="Chaining splits a complex job into focused steps. Each Claude call has one purpose."
  chart={`flowchart LR
    subgraph Refine[Refinement chain]
      A1[Prompt 1: draft] --> A2[Prompt 2: improve draft]
      A2 --> A3[Prompt 3: final pass]
    end
    subgraph Pipeline[Pipeline chain]
      B1[Prompt 1: extract entities] --> B2[Prompt 2: classify each]
      B2 --> B3[Prompt 3: write summary using results]
    end`}
/>

**Refinement** asks Claude to redo or improve its own work. The first reply is the draft; the second reply (with the draft attached) is the improvement.

**Pipeline** uses the output of one prompt as the *input data* of the next. Extract → classify → summarize is a classic three-step pipeline.

## When chaining wins

Turn 1: write a 2-sentence product blurb.

## Programmatic chaining

In code, a chain is just two API calls where the first response becomes part of the second prompt:

```python
# Step 1
draft = get_completion(
    messages=[{"role": "user", "content": "Write a 2-sentence blurb..."}]
)

# Step 2: feed draft back in
improved = get_completion(
    messages=[{
        "role": "user",
        "content": f"Improve this blurb: <blurb>{draft}</blurb>"
    }]
)
```

Programs that chain many Claude calls and decide what to do based on intermediate output are the start of **agents** — covered in depth in the Anthropic Tool Use course and the MCP courses.
